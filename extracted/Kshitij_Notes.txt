Introduction to Computer Networks 
Computer networks are crucial for facilitating communication and data transfer between 
devices. In this session, we delved into how data packets are structured and transmitted over a 
network. A key focus was the challenge of efficiently transmitting large amounts of data while 
ensuring reliable and ordered delivery. 
Concepts Discussed 
Data Packets 
●​
Definition: When transmitting data over a network, it is often broken down into small 
segments called packets. This segmentation helps in managing issues such as data 
corruption and unauthorized access. If a few packets are corrupted, only those need to be 
resent, not the entire data【6:1†source】. 
●​
Packet Formation: Packets include metadata such as source, destination, and sequence 
information to ensure they can be reordered and verified upon arrival【6:3†source】. 
Internet and Network Layers 
●​
Seven-Layer Model: The session introduced the OSI model with focus on its layers starting 
from the application layer down to the physical layer. Understanding these layers is crucial 
for comprehending how the Internet functions【6:3†source】. 
●​
Network Protocols: Protocols like TCP/IP are fundamental in governing data transfer. They 
provide rules and standards enabling different systems to communicate effectively, similar to 
how grammar facilitates human communication【6:7†source】. 
Routing and Data Flow 
●​
Routing Mechanics: Routers, switches, and other network devices manage the flow of data 
packets across various paths in a network. The data doesn't necessarily take the same path 
each time【6:16†source】. 
●​
Data Sequencing: Ensuring packets arrive in the correct sequence is vital, especially for 
streaming services like video or live broadcasts where out-of-order packets can disrupt 
content【6:13†source】. 
Network Reliability and Security

Introduction to Network Communication and Standardization 
In the development of network communication, standardization has played a crucial role in 
enabling diverse hardware and software systems to communicate effectively. Without 
standardization, manufacturers would produce incompatible devices, leading to fragmented

networks. Thus, standardization is vital to connect various devices to a unified Internet

OSI Model Overview 
The OSI (Open Systems Interconnection) model is a conceptual framework used to understand 
and implement networking standards. It has seven distinct layers, each designated to handle 
specific networking functions【8:2†transcript.txt】. Here's a breakdown of these layers: 
●​
Physical Layer: Responsible for the transmission of raw bit streams over a physical medium. 
It abstracts the physical characteristics of the communication medium (cable types, voltage 
levels)【8:4†transcript.txt】. 
●​
Data Link Layer: Ensures reliable transmission of data across a physical network link by 
managing error detection and correction from the Physical Layer. It also handles MAC 
(Media Access Control) policies【8:2†transcript.txt】. 
●​
Network Layer: Manages the routing of data packets across a network. It deals with IP 
addressing, routing, and forwarding. The Network Layer details such as IPv4 and IPv6 help 
in addressing and routing【8:11†transcript.txt】. 
●​
Transport Layer: Provides reliable transmission of data segments between endpoints on a 
network through error correction and flow control. Protocols like TCP and UDP operate here【
8:6†transcript.txt】. 
●​
Session Layer: Manages sessions in a network which delays or disruptions might interrupt. It 
controls the dialogues (connections) between computers【8:18†transcript.txt】. 
●​
Presentation Layer: Ensures the data is in a usable format and is where data encryption 
occurs. It handles data translation, encryption, and serialization【8:5†transcript.txt】【
8:18†transcript.txt】. 
●​
Application Layer: The layer closest to the end-user, it interacts directly with software 
applications to provide communication services and user interaction. This layer identifies 
communication partners, determines resource availability, and ensures appropriate 
communication 【8:10†transcript.txt】【8:5†transcript.txt】. 
Analogy with Internet Standardization 
The OSI model, while comprehensive, is often taught alongside a more commonly used TCP/IP 
model, which integrates several layers for practical implementation in Internet protocols. The 
TCP/IP model, developed by Vincent Cerf (father of the Internet), simplifies these layers and 
combines them into four broader categories: application, transport, internet, and network access 
layers【8:6†transcript.txt】【8:4†transcript.txt】. 
Data Transmission Techniques 
Packet Switching 
In the early stages of network communication, researchers developed packet switching as a 
technique to improve the reliability and efficiency of data transfer over networks. By dividing 
data into smaller packets, networks could optimize the flow and ensure that even if some

TCP/IP Protocol 
The TCP/IP protocol suite is foundational to modern networking, ensuring reliable and ordered 
delivery of data across network boundaries. TCP (Transmission Control Protocol) manages the 
packaging and delivery assurance of data packets, while IP (Internet Protocol) handles the 
addressing and routing【8:6†transcript.txt】【8:7†transcript.txt】. 
Modern Internet and Developments 
From its origin as a military and academic network to the vast, global structure it is today, the 
Internet continues to evolve. As different fields continue to expand their digital presence and 
generate more data, new technologies like DNS for domain management and IPv6 for 
expanded address space have become integral to scaling operations and managing the 
increasing demand for internet resources【8:8†transcript.txt】【8:11†transcript.txt】. 
Conclusion 
The OSI model, alongside practical models like TCP/IP, provides a foundational blueprint for 
network communication. This thorough standardization enables the wide-ranging compatibility 
necessary for today's global internet infrastructure【8:11†transcript.txt】【8:14†transcript.txt】. 
Through these layers and protocols, diverse devices across the world can communicate 
seamlessly, ensuring consistent and reliable data transmission.

Networking Class Revision Notes 
Introduction to Networks 
●​
Basic Concept: A network allows multiple devices to communicate and share resources. It 
consists of hardware like routers, switches, and hubs, and uses IP addresses to uniquely 
identify each device on the network. 
IP Addresses 
●​
IPv4: The most common form of IP address, consists of four 8-bit numbers separated by 
dots (e.g., 192.168.1.1), totaling 32 bits. This form is currently dominant despite the 
emergence of IPv6 which provides a larger pool of addresses. 
●​
IPv6: Designed to replace IPv4, it consists of 128 bits and is written as eight groups of four 
hexadecimal digits. It solves the issue of IP address exhaustion. 

===== PAGE 5 =====
Understanding IP Addressing 
●​
Binary Representation: IP addresses in routers are interpreted as sequences of bits. For 
instance, 192 in binary is 11000000【6:5†source】. 
●​
Subnet Mask: A subnet mask determines which part of an IP address is the network and 
which part is the host. For example, if the subnet mask is 255.255.255.0, the first three 
octets refer to the network. This mask aids in routing packets appropriately【6:3†source】. 
Important Concepts in IP Addressing 
●​
Network IP Address: It identifies the network itself. This address cannot be assigned to any 
individual device within the network. 
●​
Broadcast IP Address: This address is used for sending data to all devices within a network. 
It is formed by setting all the host bits to 1. 
●​
Calculating Total Devices in a Network: The number of devices that can be accommodated is 
determined by the formula 2^n - 2, where n is the number of bits assigned to host addresses. 
Two of these addresses are reserved: one for the network and one for the broadcast address
【6:1†source】【6:13†source】【6:19†source】. 
Network Devices 
●​
Router: Connects different networks together and routes data between them using IP 
addresses. They can also include switching capabilities. 
●​
Switch: Forms the backbone of a local network by directing data to specific devices using 
MAC addresses. 
●​
Hub: A basic networking device that broadcasts data to all devices in a network—less 
efficient than a switch. 
●​
Modem: Provides access to the internet by modulating and demodulating signals. 
Differences Between Network Devices 
●​
Router vs. Switch: A router connects different networks and uses IP addresses, while a 
switch connects devices within a single network using MAC addresses【6:4†source】【
6:5†source】【6:8†source】. 
●​
Router and Switch Integration: Modern routers often include switch capabilities to allow 
seamless local and external connectivity. 
Network Layer Models 
●​
OSI Model: A 7-layer model used for understanding and designing a universal set of 
communications protocols. 
●​
TCP/IP Model: A 5-layer model commonly used for structuring telecommunications protocols 
in practical use. Despite differences, the OSI model provides conceptual terms widely used 
in networking (e.g., layers 5-7 relate to applications, while TCP/IP combines them)【
6:11†source】.

Dynamic IP Addressing: IPs can change upon reconnection or system restart (dynamic), in

●​

Understanding networking fundamentals like IP addressing, subnet masks, and the role of

Address Resolution Protocol (ARP) 
Functionality 
●​
Used for mapping an IP address to a physical machine address known as a MAC (Media 
Access Control) address. Essential for local network communication【6:12†transcript.txt】. 
ARP Process 
●​
A broadcast request is sent asking, "Who has IP address X.X.X.X?" The device with that IP 
responds with its MAC address. This mapping is stored in an ARP cache for efficiency【
6:12†transcript.txt】. 
Networking Protocols 
Maximum Transfer Unit (MTU) 
●​
Specifies the largest packet size that can be sent over a network layer. If the data exceeds 
the MTU, it is fragmented across multiple packets to be transmitted【6:19†transcript.txt】. 
Network Address Translation (NAT) 
●​
Translates private IP addresses to a public IP address and vice versa, facilitating 
communication between local networks and external networks【6:14†transcript.txt】. 
Port Address Translation (PAT) or NAT Overload 
●​
Extends the capabilities of NAT by mapping multiple private IP addresses to a single public 
IP address using different ports. This helps in managing and directing responses to multiple 
devices【6:14†transcript.txt】.
