VLSM — Variable Length Subnet Masking

VLSM lets each subnet have a different prefix length — matching each department's real need instead of wasting addresses. Golden rule: allocate the largest subnet first, then work downward.

Allocate 192.168.10.0/24 for four departments
DeptHosts needed+2 → 2^NPrefixBlock
Engineering6062 → 64/2664
Marketing3032 → 32/2732
HR1012 → 16/2816
Management57 → 8/298
Allocation — largest first, no overlaps: Engineering 192.168.10.0/26 → .0 – .63 (62 usable) Marketing 192.168.10.64/27 → .64 – .95 (30 usable) HR 192.168.10.96/28 → .96 – .111 (14 usable) Management 192.168.10.112/29 → .112 – .119 (6 usable) Remaining: .120 – .255 kept for future growth
Exam
VLSM questions are graded on order + no overlap. Always start at the parent network address, jump by each block size, and show the usable range and broadcast for every subnet.

IPv6 — the 128-bit Future (Already Here)

  • Why: IPv4 exhausted — IANA ran out of free blocks in 2011. IPv6 gives 2¹²⁸ ≈ 3.4×10³⁸ addresses — effectively unlimited.
  • Format: 128 bits written as 8 groups of 4 hex digits separated by colons:
    2001:0db8:85a3:0000:0000:8a2e:0370:7334
Compression Rule 1 — drop leading zeros
0db8 → db8  ·  0000 → 0
Compression Rule 2 — one :: for the longest zero-run
2001:0db8:0000:0000:0000:8a2e:0370:7334
→ 2001:db8::8a2e:370:7334
Trap
:: may be used only once per address (two runs of zeros + :: would be ambiguous). If two runs exist, compress only the longer one (ties → the left one).

Default Gateway — Direct or Forward?

The default gateway is the router's IP on your local network — the door to every other network. Your device makes a simple decision for every destination IP X:

1. Compute X AND my_subnet_mask 2. Result == my network address? YES → X is on my subnet → deliver directly (ARP for its MAC) NO → different network → send to default gateway (ARP for gateway's MAC)
Figure 1. The routing decision every host makes before touching the network.
Worked decision — my IP 192.168.1.5/24, gateway 192.168.1.1
To 192.168.1.20: .20 AND 255.255.255.0 = 192.168.1.0 == my network ✓ → direct To 8.8.8.8: 8.8.8.8 AND 255.255.255.0 = 8.8.8.0 ≠ my network → gateway
check your gatewayterminal

NAT — Sharing One Public IP

The problem: your ISP gives you one public IP; your house has many devices. NAT (Network Address Translation) lets all of them share it, by rewriting IP:port pairs and remembering the mapping.

Figure 2. One public IP, many private devices — the router's NAT table keeps every conversation distinct by port.
Outgoing (SNAT)
Laptop: 192.168.1.5:52341 → 142.250.195.46:80 Router rewrites src: 203.0.113.5:10001 table: 10001 ↔ 192.168.1.5:52341
Reply comes back
Google → 203.0.113.5:10001 Router lookup 10001 → 192.168.1.5:52341 Delivers to laptop ✓
VariantDirectionUse case
SNAT (source NAT)OutgoingHome internet sharing
DNAT (destination NAT)IncomingPort forwarding, load balancing
PAT (Port Address Translation / overload)BothMany devices share one IP via distinct ports — what every home router does
Port forwarding (DNAT) — exposing a game server
Rule on router: public port 27015 → 192.168.1.10:27015 Friend connects to 203.0.113.5:27015 → router DNATs → 192.168.1.10:27015
Costs
NAT breaks end-to-end (inbound needs port forwarding), is stateful (router tracks every flow; reboot kills sessions), and confuses protocols that embed IPs in their payload (FTP, VoIP/SIP, some games).

Worked Examples (Exam Pattern)

Example 1 — 172.16.0.0/16 needs 500 subnets; hosts per subnet?
Host bits available = 32−16 = 16 · need 2^N ≥ 500 → N = 9 (512) Remaining host bits = 16−9 = 7 → 2⁷−2 = 126 hosts/subnet · new prefix = /25
Example 2 — compress 2001:0000:0000:0db8:0000:0000:0000:0001
Zero runs: "0000:0000" (groups 2-3) and "0000:0000:0000" (groups 5-7 — longer!) Compress the LONGER run: 2001:0:0:db8::1 (:: used once)
Speed tip
Subnet-count ↔ host-count seesaw: every bit you take from hosts doubles subnets and halves hosts-per-subnet. Keep the seesaw in your head and most MCQs answer themselves.

A1. a — 100+2=102 → 2⁷=128 → prefix /25 (126 usable).
A2. b — 2^(20−16) = 16.
A3. a — longest zero-run is groups 2–4; only one :: allowed.
A4. b — 10.1.2.0 ≠ 10.1.1.0 → off-subnet → gateway.
A5. b — 2¹⁰ − 2 = 1022.
A6. 60+2=62→64→/26. Subnets: 192.168.50.0/26 (.1–.62, bc .63), .64/26 (.65–.126, bc .127), .128/26 (.129–.190, bc .191).
A7. Variable-length prefixes per subnet to match real need; largest first guarantees later smaller blocks fit in the remaining space without overlap.
A8. Limited 255.255.255.255 — local segment only, never routed. Directed 172.16.5.255 — everyone in that specific subnet.
A9. Solves: IPv4 scarcity, one public IP for many devices, hides internal topology (accidental firewall). Creates: breaks end-to-end inbound, stateful router, protocol breakage (FTP/VoIP).
A10. The router — it creates the entry when the first outgoing packet of a flow passes. That's why unsolicited inbound has no entry and is dropped unless port-forwarded.
