Networks as Graphs

A graph G = (V, E): V = routers (vertices/nodes), E = links (edges), and each edge carries a weight = link cost (latency, bandwidth-derived cost, or hop cost). Our running example — a 5-city network:

Figure 1. The running example graph used for every trace in this lecture.

Choice
The Internet is sparse (each router connects to a few others) → adjacency list wins: O(V+E) space vs O(V²) for the matrix.

BFS — Breadth-First Search

What BFS finds
The minimum hop-count path from source to every reachable node. Uses a queue (FIFO); explores layer by layer: 1 hop away, then 2 hops, then 3…
Limitation
BFS minimises hops, not cost. A 1-hop path costing 100 beats a 3-hop path costing 3 — wrong for cost-based routing. For cost, use Dijkstra (§4).
bfs with path trackingJAVA
static List<String> bfsPath(Map<String, List<Edge>> g, String start, String end) { Deque<List<String>> queue = new ArrayDeque<>(); Set<String> visited = new HashSet<>(); queue.add(List.of(start)); visited.add(start); while (!queue.isEmpty()) { List<String> path = queue.poll(); // FIFO — the queue is the whole trick String node = path.get(path.size() - 1); if (node.equals(end)) return path; // first visit = fewest hops for (Edge e : g.get(node)) { if (visited.add(e.to())) { List<String> next = new ArrayList<>(path); next.add(e.to()); queue.add(next); // carry the path alongside } } } return null; // end unreachable from start }
bfs with path trackingC++
vector<string> bfsPath(map<string, vector<pair<string,int>>>& g, string start, string end) { queue<vector<string>> q; set<string> visited; q.push({start}); visited.insert(start); while (!q.empty()) { auto path = q.front(); q.pop(); // FIFO — the queue is the whole trick string node = path.back(); if (node == end) return path; // first visit = fewest hops for (auto& [nb, w] : g[node]) { if (!visited.count(nb)) { visited.insert(nb); auto next = path; next.push_back(nb); q.push(next); // carry the path alongside } } } return {}; // end unreachable from start }

DFS — Depth-First Search

DFS explores as deep as possible along one branch before backtracking — a stack (or recursion) instead of a queue. Finds a path, not necessarily the shortest. O(V+E).

dfs — iterative + cycle detectionJAVA
static List<String> dfsIterative(Map<String, List<Edge>> g, String start) { Deque<String> stack = new ArrayDeque<>(List.of(start)); Set<String> visited = new HashSet<>(); List<String> order = new ArrayList<>(); while (!stack.isEmpty()) { String node = stack.pop(); // LIFO — go deep first if (visited.add(node)) { order.add(node); for (Edge e : g.get(node)) if (!visited.contains(e.to())) stack.push(e.to()); } } return order; } static boolean hasCycle(String node, Set<String> visited, Set<String> recStack, Map<String, List<Edge>> g) { visited.add(node); recStack.add(node); // on the current path for (Edge e : g.get(node)) { if (!visited.contains(e.to())) { if (hasCycle(e.to(), visited, recStack, g)) return true; } else if (recStack.contains(e.to())) { return true; // back edge = cycle! } } recStack.remove(node); // leave the current path return false; }
dfs — iterative + cycle detectionC++
vector<string> dfsIterative(map<string, vector<pair<string,int>>>& g, string start) { stack<string> st; st.push(start); set<string> visited; vector<string> order; while (!st.empty()) { string node = st.top(); st.pop(); // LIFO — go deep first if (!visited.count(node)) { visited.insert(node); order.push_back(node); for (auto& [nb, w] : g[node]) if (!visited.count(nb)) st.push(nb); } } return order; } bool hasCycle(const string& node, set<string>& visited, set<string>& recStack, map<string, vector<pair<string,int>>>& g) { visited.insert(node); recStack.insert(node); // on the current path for (auto& [nb, w] : g[node]) { if (!visited.count(nb)) { if (hasCycle(nb, visited, recStack, g)) return true; } else if (recStack.count(nb)) { return true; // back edge = cycle! } } recStack.erase(node); // leave the current path return false; }

Network uses of DFS
  • Topology discovery — walk every reachable router
  • Cycle detection — a cycle in the routing graph = a potential routing loop (packets circling forever)
  • Spanning-tree construction (preview of Lecture 6 / STP)

Dijkstra — Minimum-Cost Paths

Idea
Greedy: always expand the cheapest unfinished node; relax its neighbours. A min-heap serves the cheapest node fast.
Guarantee
Optimal costs to ALL nodes — but only when all edge weights ≥ 0 (why: Lecture 6).
Complexity
O((V+E) log V) with a binary heap — the price of the priority queue, worth it for correct costs.
dijkstra + path reconstructionJAVA
record PQ(int cost, String node) {} static Map<String, Integer> dijkstra(Map<String, List<Edge>> g, String src, Map<String, String> prev) { Map<String, Integer> dist = new HashMap<>(); g.keySet().forEach(n -> dist.put(n, Integer.MAX_VALUE)); dist.put(src, 0); var pq = new PriorityQueue<PQ>(Comparator.comparingInt(PQ::cost)); pq.add(new PQ(0, src)); while (!pq.isEmpty()) { var top = pq.poll(); if (top.cost() > dist.get(top.node())) continue; // stale entry — skip for (Edge e : g.get(top.node())) { int nc = top.cost() + e.w(); if (nc < dist.get(e.to())) { // relax dist.put(e.to(), nc); prev.put(e.to(), top.node()); pq.add(new PQ(nc, e.to())); } } } return dist; } // path: follow prev[] from target back to source, then reverse.
dijkstra + path reconstructionC++
map<string, int> dijkstra(map<string, vector<pair<string,int>>>& g, string src, map<string, string>& prev) { map<string, int> dist; for (auto& [n, _] : g) dist[n] = INT_MAX; dist[src] = 0; priority_queue<pair<int,string>, vector<pair<int,string>>, greater<>> pq; pq.push({0, src}); while (!pq.empty()) { auto [cost, node] = pq.top(); pq.pop(); if (cost > dist[node]) continue; // stale entry — skip for (auto& [nb, w] : g[node]) { int nc = cost + w; if (nc < dist[nb]) { // relax dist[nb] = nc; prev[nb] = node; pq.push({nc, nb}); } } } return dist; } // path: follow prev[] from target back to source, then reverse.

Network = graph: routers V, links E, weight = cost.

Answer Key
A1. b — queue (FIFO) vs stack (LIFO).
A2. b — greedy finalisation is wrong when a longer route later becomes cheaper.
A3. a — 2 + 2 = 4 beats 10 and 12.
A4. b — sparse → list is compact and fast.
A5. b — OSPF; RIP is BFS-like hop count.
A6. V = routers, E = links, weight = cost. Realistic: latency (ms) or bandwidth-derived cost (Lecture 8).
A7. Dense graphs / constant-time edge lookup. List O(V+E); matrix O(V²).
A8. BFS ignores weights — 1 hop costing 100 "wins" over 3 hops costing 3.
A9. A back-edge to a node in the current recursion stack. In routing = packet-loop risk.
A10. Lazy deletion: a better route may have popped first; stale heap entries must be skipped.
A11. Order: Chennai → Delhi → Bangalore → Mumbai → Hyderabad. Hops: Delhi 1, Bangalore 1, Mumbai 2, Hyderabad 2.
A12. Expansions: Delhi(0) → Mumbai(5), Hyderabad(2) → Bangalore(4) → Chennai(8)... full: Delhi 0, Hyderabad 2, Mumbai 5, Bangalore 4, Chennai 8; Delhi→Chennai = Delhi → Hyderabad → Bangalore → Chennai (cost 8).
A13. See code block; heap = next-cheapest node in O(log V); relaxation = improve dist via neighbour; prev[] = rebuild path backwards.
A14. RIP = distributed BFS (hop metric); OSPF = every router runs Dijkstra on the LSDB; a routing loop is exactly a cycle packets can traverse — detected/avoided via topology knowledge.
